# Mercury 版本更新交互原型

这是 Mercury 系统的版本更新交互页面，可用于评审与前端开发对接。

## 已实现流程

- 检测新版本，并展示版本号、更新说明和更新大小
- “立即下载”与“稍后下载”操作
- 弹窗缩小并飞入右下角下载进度悬浮框
- 下载失败状态的独立演示入口
- 下载完成后的安装确认与“安装完成后自动重启”选项
- 安装进度、安装完成及手动重启流程
- Mercury 客户服务中心入口、二维码与联系电话气泡

## 本地预览

这是一个无构建依赖的静态页面。进入仓库目录后启动任意静态服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

> 客服二维码与电话号码目前是演示占位内容，接入正式环境前请替换。
